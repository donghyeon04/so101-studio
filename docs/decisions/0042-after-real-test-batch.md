# 0042. 실물 시험 뒤 결정 묶음: 물체 높이 전달, 그리퍼 속도, 교시 재생 변환, 오류 문구, 설정 바로 적용, 조그 값 입력

상태: 확정 · 2026-11-06 (기획 세션 한도로 사용자가 로컬 총괄과 정함)

## 맥락
2026-11-06 실물 시험(`measurements.md`)과 GUI 사용에서 나온 요청이다. 58×58×39mm 물체 집기 5회 중 2회는 V자로 기울인 턱이 물체 위 모서리를 쳐서 실패했다(통과 조건 W ≤ G − (H − t)·s(G) − 4, 지금 설정이면 H39 물체는 W≤44mm). 손으로 녹화한 동작은 1배속에서 한 주기 이동량(5°/20ms) 검사에 걸려 멈췄다.

## 결정
1. **물체 높이 전달**: `DetectedObject`에 `height_mm`(선택, 0 = 모름)을 더한다. 수동 입력에 높이 칸, 초음파는 확인 결과의 실측 높이를 넣는다. `pick`은 높이를 알면 물체마다 턱 끝 높이를 위 통과 조건으로 정하고, 모르면 설정값(`grasp_height_mm`)을 쓴다. 그때까지 임시로 `grasp_height_mm` 20, `grasp_max_open_mm` 90(REQ-033).
2. **그리퍼 속도**: 팔에 새 설정 `gripper_speed_pct`(바로 적용)를 둔다. GUI 상단 막대가 이 값을 바꾼다. `gripper_acceleration`(접촉 감지 기준)은 그대로.
3. **초음파 접근 호버 도달 띠**: 지금 유지. 벤치마크(#121) 손실 2~4%p. 초음파 실물(A1) 때 다시 본다.
4. **교시 재생 변환**: 한 주기 이동량·가속 한도를 넘는 구간만 늦춘 "재생 가능본"을 만들고, 재생 방식을 원본/변환본 중 고른다. 원본도 한 주기 이동량 검사는 끄지 않는다.
5. **오류 문구**: fault마다 원인과 해결법을 사람이 읽게 한다(예: "한 주기 이동량 초과: 팔꿈치 7.2°(한도 5°), 배속을 낮추세요"). 팔은 fault에 관절·값·한도를 담고, GUI는 알림과 상태줄에 보인다.
6. **작업대·좌표 설정 바로 적용**: 저장하면 실행 중인 앱에 바로 반영한다. 작업 실행 중에는 저장을 막는다.
7. **조그 값 직접 입력**: 직접 조작에 관절별 목표 각도 입력과 [이동]. 기존 관절 이동 API와 안전 검사를 그대로 쓴다.
