# 0051. 0° 확인 잠금만 걸렸을 때는 home 이동을 허용한다

상태: 확정 · 2026-11-11 (사용자 승인, #233으로 이미 구현). 0029의 잠금을 보완한다.

## 맥락
0029는 캘리브레이션을 저장한 뒤 0° 자세를 확인하기 전까지 움직이는 명령을 모두 잠근다. 그런데 `--verify-zero`가 중간에 끝나거나 실패하면 팔이 편 자세(0°)에 남는다. 그 자세에서 쉬는 자세로 돌아갈 명령이 없어 사람이 팔을 받쳐야 했다(#233).

## 결정
- 잠금 이유가 **0° 확인 필요뿐일 때**는 `home` 이동만 허용한다. 속도는 지금 `home`과 같고 안전 검사도 모두 적용한다.
- 캘리브레이션 불일치나 팔 파일 없음 잠금은 그대로 모든 움직임을 막는다. 캘리브레이션이 틀렸으면 home 자세도 틀린 곳이기 때문이다.
- 다른 움직이는 명령은 0029대로 0° 확인 뒤에 풀린다.

## 영향
- 팔: `ArmService`의 잠금 검사(#233에 구현됨).
- GUI: 잠긴 동안에도 [홈] 버튼은 0° 확인 잠금일 때만 켠다.
