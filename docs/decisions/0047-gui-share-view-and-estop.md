# 0047. GUI 다른 기기 보기는 `--share`일 때만 열고, 원격은 보기 전용, E-STOP은 모든 화면에

상태: 확정 · 2026-11-07 (사용자 승인으로 합침). 0023의 "127.0.0.1에만 연다"에 예외 하나를 더한다.

## 맥락
운영자 화면(gui-spec 12.4)은 시연 때 다른 기기(노트북, 휴대폰)에서 상태와 3D를 보는 쓰임을 적었다. 그러나 앱은 결정 0023대로 `127.0.0.1`에만 열려 같은 PC에서만 보인다. NiceGUI 기본값 `0.0.0.0`으로 열면 같은 네트워크 누구나 첫 접속으로 조작권을 가져가 팔을 움직일 수 있다. 또 E-STOP을 보기 전용 브라우저에 둘지가 문서(2절·12.4)와 코드(`app.py`는 보임, `operator.py`는 숨김)에서 엇갈렸다(EGM 대조, 2026-11-07).

## 결정
1. 기본은 지금처럼 `127.0.0.1`. `so101.cmd gui --share`로 시작했을 때만 NiceGUI와 Viser를 `0.0.0.0`에 열고, 운영자 화면에 `http://<PC IP>:<포트>/operator`를 보인다.
2. 접속 주소가 이 PC(루프백)가 아닌 브라우저는 조작권을 가질 수 없다. 늘 보기 전용이다.
3. E-STOP은 조작권과 상관없이 모든 화면, 모든 브라우저(원격 보기 전용 포함)에 둔다. 세우는 쪽은 안전한 방향이므로 막지 않는다. 시연 중 잘못 눌러 멈추는 일은 [정지 해제]로 되돌린다.
4. 인증은 넣지 않는다. `--share`는 신뢰하는 네트워크에서 시연할 때만 쓰고, 시작할 때 "같은 네트워크의 누구나 볼 수 있고 E-STOP을 누를 수 있습니다"를 알린다.

## 영향
- GUI 세션: `--share` 인자, 원격 브라우저 조작권 거부, 운영자 화면 E-STOP 표시, 3D 주소를 요청 호스트로(gui-spec 12.4·12.5).
- 팔·초음파 세션: 영향 없음.
