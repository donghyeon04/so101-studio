# 0029. 기존 값이 없거나 다른 팔의 자동 캘리브레이션은 3회 반복으로 합격시키고, 저장 뒤 0° 자세를 사람이 확인한다

상태: 확정 · 2026-11-03 (0028을 보완, 0° 확인 잠금만일 때 home 허용 → 0051)

## 맥락
REQ-016(PR #38)에서 측정만 모드의 합격 기준은 "기존 캘리브레이션 파일과 ±3° 이내"다. 이 기준으로는 파일이 없는 새 팔은 저장할 수 없고, 기존 파일이 틀린 팔도 저장할 수 없다(이 팔의 shoulder_pan 239°가 그 후보). 선택지 세 개(반복성, 표준 팔 값과 비교, 사람 확인 후 강제 저장) 가운데 사용자가 반복성 기준을 골랐다.

## 결정
- 합격은 두 갈래다. ① 기존 파일이 있고 모든 관절이 ±3° 이내: 1회 측정으로 합격(지금과 같음). ② 그 밖의 경우: 최근 24시간 안의 같은 팔 측정만 결과 3개가 모두 엔진의 관절 허용 범위 검사를 통과하고, 3회 사이 관절별 범위와 0° 위치 차이가 모두 1° 이하이면 "반복 합격"이다.
- 반복 합격일 때 저장 값은 3회의 관절별 중앙값이다. 기존 파일이 있으면 저장 전에 차이표를 보여 주고, 사람이 `yes`를 입력해야 저장한다. 이전 파일은 0028대로 `.bak.json`으로 남긴다.
- 저장한 뒤에는 0° 자세 확인을 해야 움직이는 명령이 풀린다. 속도 20%로 전 관절을 0°로 보내고, 사람이 실물과 3D(URDF) 자세를 비교해 확인한다. 확인하면 팔 파일에 날짜와 캘리브레이션 파일의 해시를 남기고, 해시가 지금 캘리브레이션 파일과 다르면 0027의 잠금(`locked`, 읽기만)을 건다.
- 구현은 팔 세션(REQ-017)이 하고, GUI 캘리브레이션 마법사(나중)는 이 두 갈래와 0° 자세 확인을 그대로 화면으로 옮긴다.
