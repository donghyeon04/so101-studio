# 0070. 시계 주입(mujoco-spec 13.10.2)을 12/4 전에 한다

상태: 확정 · 2026-11-18 (사용자 요청: 수집·평가 시간 단축. 결정 0066 상태 줄의 "시계 주입은 2차(12/4 뒤)"를 바꾼다. 세부 설계는 `mujoco-spec.md` 13.10.2, EGM Stage 9 꼭 고칠 것 9개 반영)

## 맥락
- ACT 수집 다시 짜기(결정 0068)와 접근 각도 비교(결정 0069)로 수집·학습·평가를 여러 번 돌려야 한다. 실시간으로는 한 바퀴에 5~6시간이고, `--jobs`를 늘리면 `realtime_lag`로 에피소드를 버린다.
- 2026-11-16 밤에는 "팔 핵심 세 파일을 실물 팔이 오는 주에 고치는 위험"으로 미뤘다. 지금은 실물 팔이 없고, 단계를 셋으로 나누면 첫 단계(팔)는 동작이 바뀌지 않는다.

## 결정
- 13.10.2를 지금 구현한다. 순서는 ① 팔: `Clock` 규약 + `WallClock`(동작 변화 없음) → ② MuJoCo: `StepClock` → ③ MuJoCo: 시험장·기록기·정책 평가 연결.
- 목적은 넷이다: 실시간보다 빠르게, `realtime_lag` 버림 없애기, `--jobs` 늘리기, 같은 씨앗이면 같은 결과(58mm 미끄러짐 편차의 원인 가르기).
- 실물 팔 기본 동작은 바뀌지 않아야 한다. ①을 합친 뒤 실물 확인을 한 번 한다(하드웨어라 사용자에게 먼저 묻는다).
- 빠른 모드에서도 보기 창을 쓸 수 있게 한다(화면 밖 렌더를 몇 프레임마다 그림). MuJoCo 수동 뷰어는 실시간 모드에서만 쓴다.

## 영향
- 팔 세션 ①, MuJoCo 세션 ②③. 초음파 `RealClock`·`SimClock`은 옮기지 않는다(13.10.3에서 연결).
