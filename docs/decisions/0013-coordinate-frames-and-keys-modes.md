# 0013. 좌표계는 월드(작업대)·베이스(로봇)·툴 세 가지, 높이는 작업대 면 기준

상태: 확정 · 2026-11-01

## 맥락
키보드와 나중의 GUI(시뮬레이션에서 점 찍기)가 x y z를 입력할 때 기준점이 불분명했다. 산업용 로봇(Doosan, xArm, KUKA, ABB, FANUC, UR)과 MoveIt Servo, Tormach 조그는 월드/베이스/툴 프레임을 고르게 하고, 툴 프레임은 상대 이동만 받는다.

## 결정
- `table`(= world): 작업대 왼쪽 아래 원점. `robot`(= base): 어깨 회전축 원점, 앞/왼쪽. `tool`: 상대 이동만, z = 도구 앞, x = 턱 벌어지는 축.
- 높이는 모든 좌표계에서 작업대 면 위 mm(`table_z_mm`가 기준). 입력점은 `tcp tip`(고정 턱 끝, 기본) 또는 `ref`(고정 턱 안쪽 면).
- `keys`: Tab으로 관절 → 직교 조그(f로 로봇/툴 기준) → 좌표 입력. 안 닿는 점은 `preview_tool`로 거부하고 움직이지 않는다.
- GUI는 `ArmService.point_pose` + `preview_tool` + `move_tool`을 그대로 쓴다.
- 5축이라 툴 프레임의 자세 변경(기울이기)은 받지 않는다.
