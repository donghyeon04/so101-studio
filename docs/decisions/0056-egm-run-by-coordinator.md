# 0056. EGM 설계서 점검은 총괄이 하위 에이전트로 직접 돌린다

상태: 확정 · 2026-11-12 (사용자 승인, 로컬 총괄). 0048의 실행 방식(사용자가 새 세션에서 슬래시 명령을 직접 입력)만 바꾼다. 무엇을 언제 점검하는지(Stage 9, drift-report)는 0048 그대로다.

## 맥락
- 0048은 EGM 스킬이 `disable-model-invocation`이라 사용자가 직접 `/egm:egm-review`를 치게 했다. 사용자가 자리에 없으면 설계서 점검이 멈췄다.
- EGM 문서(docs/claude.md)는 Claude Code에서 스킬 파일을 읽고 같은 흐름을 따르며 리뷰어를 `Agent` 하위 에이전트로 띄우는 방식을 허용한다. 2026-11-11 밤 MuJoCo 13절 3라운드와 gui-spec 12.7을 이렇게 돌렸고, 리뷰어 셋(구현 준비도·코드 대조·문체)이 각자 새 맥락에서 실제 어긋남을 찾았다.

## 결정
1. 총괄(GUI 세션)이 `egm:egm-synthesizer` 하위 에이전트에 대상 절·GoldfishContext·리뷰어 셋을 넘겨 Stage 9를 돌린다. 리뷰어는 각자 새 맥락이다. 결과는 `runs/egm/<날짜>-<주제>/`.
2. 합쳐지지 않은 설계서·코드는 임시 worktree에 모아(예: PR 브랜치 코드 + 기획 브랜치 설계서) 리뷰어가 같이 보게 한다.
3. 꼭 고칠 것만 [기획 요청]으로 올리는 것, 사용자 승인 뒤 합치는 것은 0048 그대로다.
