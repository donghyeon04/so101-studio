# 0059. 막힘·접촉은 추종 오차(명령 − 실제)로 먼저 잡고, 동작마다 문턱을 따로 둔다

상태: 초안(승인 대기) · 2026-11-13 (`researching-references`, 후보 13개)

## 맥락
지금 감시는 그리퍼 부하 60% 1초(0033)와 관절 부하 90% 3초다. 부하는 2Hz로 서보마다 하나씩 읽는다. 그래서 순간 접촉을 못 잡는다(쥔 물체 위로 다시 닫기, 홈·0°로 가다 걸림). 접촉 판단 `contact_lag_units`는 집기 닫기 안에서만 쓴다.

## 결정(안)
1. **신호**: 관절마다 추종 오차 e = 마지막 명령 − 실제 위치(°)를 쓴다. 상태 루프가 10Hz로 이미 읽는 위치를 쓰므로 버스 읽기를 더하지 않는다. STS3215 위치 모드에서 `Present_Load`는 e에 비례하고 작은 값은 0으로 떨어진다. `Present_Current`는 몇 단위뿐이라 문턱 신호로는 거칠다(SO-101 실측 사례).
2. **문턱**: 정상 이동에도 서보 안 가속과 P 제어 때문에 오차가 생긴다. 그래서 고정값이 아니라 동작 프로필별 "정상 실행 최대 × 1.3"으로 시작한다(0033과 같은 방식). 연속 2회(약 0.2초) 넘으면 막힘으로 본다. 정속 구간 오차는 속도에 비례한다고 보고 문턱도 속도 비율로 늘린다(실측으로 확인).
3. **프로필 셋**: 빈 이동, 쥔 채 이동, 그리퍼 닫기. 프로필마다 가속·감속 구간(궤적 앞뒤 약 0.2초)과 정속 구간의 문턱을 따로 둔다(Franka의 가속/정속 분리).
4. **반응**:
   - 팔 관절은 목표를 지금 위치로 맞춰 멈추고 WARN `ARM-BLOCKED`(관절·오차·문턱)를 남긴다. 다음 동작은 사람이 고른다.
   - 그리퍼는 집기 밖의 닫기(`gripper` 명령, 홈 등)에도 같은 접촉 판단을 적용해 "지금 위치 + 예압"으로 멈춘다(0033).
5. **기존 감시 유지**: 부하 감시(그리퍼 60%, 관절 90% 3초)는 두 번째 안전망으로 그대로 둔다. 부하를 10Hz `sync_read`로 빨리 읽는 안은 오차 감시로 모자랄 때만 더한다.
6. **검증**:
   - 판정 논리는 MuJoCo로 먼저 본다. 장애물에 막힌 홈 이동이 멈추는지, 빈 이동에서 오탐이 0인지 확인한다.
   - 문턱 숫자는 실물 정상 실행 5회씩으로 정한다. MuJoCo 액추에이터의 오차는 실물 서보와 다르다.
   - 구현은 승인 뒤 총괄이 팔 세션에 REQ로 낸다. 설계서는 arm-software-spec 6.1(감시)에 더한다.
