# 0017. 직접 교시는 토크를 끈 방식을 기본으로 하고 추종 교시는 실험 기능으로 둔다

상태: 대체됨(→ 0018) · 2026-11-01

## 맥락
결정 0016의 추종 교시(토크 제한·P·D 조절, 중력 보상, 이동 방향 보조)를 실제 팔로 여섯 번 시험했으나 모두 "뻑뻑하고 어색하다"였다. 교시 중 서보 부하는 작아(최대 24~80, 팔꿈치 한때 376) 원인은 서보 설정이 아니라 1/345 기어 마찰이었다. 중력 보정(`gravcal`)은 정지 부하가 마찰·접근 방향에 좌우되어 r2 0.01~0.75로 쓸 수 없었다.
레퍼런스 조사: LeRobot 공식 문서는 팔로워에 1/345 기어만 쓰고, 손으로 움직이는 리더는 1/191·1/345·1/147을 섞어 "힘을 적게 들이고 움직일 수 있게" 한다. SO-100/101 사례(Foxglove 튜토리얼, 커뮤니티 설정 저장소)는 팔로워를 손으로 움직일 때 토크를 끄고(`disable_torque`), 팔을 들어 올린 채 풀면 떨어지므로 먼저 받침에 내려놓으라고 한다. STS3215 팔로워에서 컴플라이언스나 중력 보상을 구현한 사례는 찾지 못했다.

## 결정
- `record <이름>`(토크 끔, 손으로 받쳐서 가르침)을 직접 교시의 기본으로 한다.
- 추종 교시(`record --follow`)는 실험 기능으로 코드에 남기되 권장하지 않는다. 중력 보상(`gravcal`)도 같다.
- 리더 팔과 PWM 모드는 만들지 않는다.
