# 0011. 벌린 손을 기울여 V자를 대칭으로 만들고 닫을수록 푼다

상태: 확정 · 2026-11-01

## 맥락
0010 방식에서도 고정 턱이 수직으로 서고 가동 턱만 크게 벌어져 한쪽으로만 벌려 찍는 모양이었다. 사용자는 벌린 모양이 양쪽으로 대칭인(약 45° 방향) V자이길 원했다.

## 결정
- 턱 끝 위치를 URDF 메쉬로 계산한 표(`kinematics.py`의 `JAW_TIP_*`)로 두 턱 끝의 위치를 구하고, 두 턱 끝의 중간점이 물체 중심에, 낮은 턱 끝이 `grasp_height_mm`에 오도록 손 자세를 정한다(`jaw_tip_offsets`).
- 턱 축이 팔이 뻗은 방향(앞뒤, `grasp_tilt_tol_deg` 이내)일 때만 손을 가동 턱 반대쪽으로 기울인다. 기울기는 두 턱 끝 높이가 같아지는 각도(최대 `grasp_tilt_deg`=25°, 값 65에서 약 23°)이고 닫을수록 0으로 푼다. 5축 팔이라 좌우로는 기울일 수 없어 그때는 기울이지 않는다.
- 접근 높이에서는 기울기를 절반만 주고(손목 한계), 내려가는 직선 경로가 pitch를 보간한다. 그리퍼 값↔관절각은 q = -10 + 1.214 v(카드 시험 2점에 맞춘 가정).
- `kinematics.fk`의 pitch는 부호를 유지한다(-90 수직, -115 = 25° 기울임).
