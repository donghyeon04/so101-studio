# 0038. 초음파 확인은 정확·빠른 두 모드를 두지 않고 하나로 한다

상태: 확정 · 2026-11-05 (0034의 "정확 모드와 빠른 모드를 둔다" 대체)

## 맥락
결정 0034는 정확 모드와 빠른 모드를 두었다. 빠른 모드의 차이는 T8(접근 경로를 첫 확인선으로)과 T9(확인선 일찍 멈춤)였다. T9는 지금 `follow_path`로는 시간을 오히려 늘려 두 모드 모두 껐다(`ultrasonic-spec.md` 4절). 8.5절 벤치마크 공식 표(커밋 c3b47d8, 씨앗 20)에서 빠른 모드는 정확 모드와 인식 시간 -3~+4%, 성공 -2~+7%p로 거의 같았고, 빠른 모드 임시 기준(평균 60초)도 넘었다(62~65초). 사용자가 하나로 합치는 안을 승인했다.

## 결정
- 초음파 확인 모드는 하나다. 설정의 `mode`(accurate | fast)를 없앤다.
- T8은 옵션 `check.approach_line`(기본 끔)으로만 남긴다. T9는 경로 안에서 멈추는 기능이 생길 때까지 끈다.
- 합격 기준은 1절의 한 줄(물체 3개 10회 평균 2개 이상, 인식 평균 70초 이하, 임시)만 쓴다. I1도 한 번만 한다.
- 시간을 더 줄이는 일은 U9에서 확인 경로 속도·가속 실측과 T8 비교로 한다.
