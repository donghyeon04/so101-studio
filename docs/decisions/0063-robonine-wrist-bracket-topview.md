# 0063. 그리퍼는 로보나인 병렬, 손목에는 짧은 초음파 브래킷만(0°), 카메라는 탑뷰 하나

상태: 확정 · 2026-11-14 (사용자 방향 확정, 총괄 오후 보고 1절. 0035의 손목 브래킷 부분과 0043-1의 기본 그리퍼를 대체) · 2026-11-20 1항의 "교체(U5) 뒤 기본값 `parallel`"을 U5 전으로 앞당김(사용자 지시, 총괄 경유, REQ-098. 실물에 단동식이 달린 동안은 `local.yaml`에 `gripper: single_jaw`)

## 결정
1. **그리퍼**: 시연·시험의 기준 그리퍼는 Robonine SO-ARM100/101 Parallel Gripper(`gripper: parallel`)다. 교체(U5) 뒤 팔 파일 기본값을 `parallel`로 바꾼다. 단동식은 예비로 코드·설정을 남긴다. 단동식 전용 규칙(기울여 집기 0060, 45° 정사각형 A+B, `grasp_tilt_tol_deg`)은 로보나인에는 해당 없다.
2. **손목**: 팀 CAD "Gripper(브라켓 짧은 버전)"의 초음파 브래킷만 단다. 센서는 0°(그리퍼 축과 평행하게 아래)다. 센서 오프셋은 CAD 값 {0.0, 66.5, 99.5}mm(센서 면이 작업 면 위 약 155mm에서 확인)이고, 장착 뒤 A0로 고친다. 손목 카메라는 달지 않는다.
3. **카메라**: 작업대 위 탑뷰 하나(0058 그대로).
4. **다시 맞추는 순서**:
   - 실물: 교체(U5) → 캘리브레이션 그리퍼 범위 측정 → 폭 표·접촉·조임 실측(runbook 2-10, `config/grippers/parallel.yaml`) → 2-2 재시험(30%·50%, 0061 문턱 다시 재기) → 브래킷 출력(U7)·장착 → A0 → A1.
   - MuJoCo: 로보나인 손 모델(M4b) → 로보나인 + 브래킷 + 센서 조립을 뷰어로 확인 → M5·M6를 로보나인 손 위에서(`mujoco-spec.md` 13.10).
   - 초음파: 센서 오프셋 REQ(보냄), 새 센서 높이에 맞춘 확인 높이·경로는 M6 벤치마크로 다시 고른다.
