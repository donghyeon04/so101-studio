# 0073. 세계 다시 짓기와 정책 실행 화면의 [다음 배치]·판정을 1차(12/4 전)로 옮긴다

상태: 확정 · 2026-11-19 (사용자 결정. 총괄이 GUI 정책 실행 학습 배치 #487로 구현했고 기획이 설계서를 맞춘다. 결정 0066 상태 줄의 2026-11-17 3a 자르기 가운데 이 셋만 바꾼다)

## 맥락
- 3a 범위 자르기(2026-11-17)는 세계 다시 짓기를 "GUI ② 수집 화면과 ③ [다음 배치]에만 필요"하다고 보고 2차로 미뤘다.
- ACT 2차(결정 0071) 정책을 GUI에서 보일 때, 앱을 켤 때의 물체는 학습 묶음의 배치(반경·방위·각도)와 다르다. 학습 때 묶음의 씨앗 배치에 상자를 놓아야 명령줄 평가와 같은 조건이 된다.
- 필요한 조각이 작다: 드라이버 `set_objects`, `connect(fresh=True)`, GUI `rebuild_world` 한 함수.

## 결정
1. 세계 다시 짓기(`mujoco-spec.md` 13.10.4)는 1차다. 모양은 `Backend.rebuild_world(suite, seed)`이고 묶음은 체크포인트의 `meta/collect.json`에서 읽는다.
2. GUI ③ 정책 실행 화면에 학습 배치 스위치(기본 켬)·씨앗·[다음 배치]를 두고, 끝나면 `judge` 판정을 보인다(`gui-spec.md` 12.10). 성공률 표는 그대로 명령줄 평가(씨앗 50개)로 낸다.
3. 그대로 2차인 것: GUI ② 수집 화면, 데이터셋 이어 쓰기, ③의 [일시 정지]·[다시 시작], 강화학습 데모.
