# 0028. 자동 캘리브레이션은 LeRobot PR #4826 엔진을 가져와 측정만 하는 모드부터 시작한다

상태: 확정 · 2026-11-03

## 맥락
수동 캘리브레이션(`lerobot-calibrate`)은 처음 세 번 실패했고(통신 끊김 2회, 가운데 자세가 나빠 범위가 0~4095로 튄 것 1회), 새 팔마다 반복해야 한다. LeRobot은 관절 0°를 기록한 범위의 가운데로 정하므로, 손으로 끝까지 밀었는지에 따라 0°가 달라진다. 레퍼런스 12개 가운데 LeRobot PR #4826(`lerobot-calibrate --auto`, 열린 PR, Apache-2.0)이 같은 문제를 푼다. 실물 SO-101 두 대로 시험했고, 가짜 서보 테스트가 52개 있으며, LeRobot 0.6.1 버스 API와 맞는다. `arm-dev-status.md`의 "새 팔은 자동 설정하지 않는다"를 바꾸므로 새 결정으로 남긴다.

## 결정
- 자동 캘리브레이션은 직접 설계하지 않는다. PR #4826의 엔진, SO 계획, 테스트를 `arm/autocal/`로 가져와 이 팔에 맞춘다. 출처 커밋과 라이선스를 남기고, LeRobot이 합치면 upstream으로 바꾼다.
- 방식은 완전 자동이다. 위치 모드에서 목표를 최대 12°만 앞세워 토크 50%로 끝단까지 밀고, 끝단 감지·시간 초과·외부 접촉·범위 이상이면 결과 없이 멈추고 레지스터를 되돌린다. 실행 중 변경은 `Lock=1`로 RAM에만 남긴다.
- 첫 단계는 `so101 calibrate --auto --measure-only`다. EEPROM에 쓰지 않고, 기존 캘리브레이션과 관절별 차이를 보여 준다. 실물 시험에서 기존 값과 ±3° 이내, 3회 반복 차이 1° 이하를 확인한 뒤에야 `--save`를 쓴다.
- `--save`는 이전 파일을 날짜 붙은 `.bak.json`으로 남기고 EEPROM(`Homing_Offset`, `Min/Max_Position_Limit`), LeRobot 캐시, `config/calibration`에 쓴다. 팔 파일의 `physical_limits_deg`는 제안만 하고 사람이 고친다.
- 계획 파일의 관절 허용 범위는 이 팔 값으로 고친다. shoulder_pan(수동 239°, PR 185~205°)과 그리퍼(125°)는 실물 확인 뒤 정한다.
- 실행 조건: 클램프 고정, 반경 50cm 비우기, 사람이 전원 스위치 옆에 있기, 전압 11.0V 미만이나 온도 60°C 초과면 중단. 수동 `lerobot-calibrate`는 대안으로 그대로 둔다.
- 구현은 팔 세션(REQ-016)이 하고, GUI 캘리브레이션 마법사는 그 뒤 GUI 세션이 한다.
