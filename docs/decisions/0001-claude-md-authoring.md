# 0001. CLAUDE.md 작성 방식

상태: 확정 · 2026-10-31

## 맥락
여러 계정과 원격/로컬 세션을 오가므로 모든 세션이 같은 규칙으로 일해야 한다. 반면 CLAUDE.md는 매 세션 전부 읽히기 때문에, 불필요한 내용은 비용만 늘리고 성공률을 떨어뜨린다.

## 검토한 대안
- 모든 원칙, 절차, BOM을 CLAUDE.md 한 파일에 넣기
- AGENTS.md를 원본으로 두고 CLAUDE.md는 링크로 두기 (LeRobot 방식)
- CLAUDE.md는 짧게 유지하고 절차는 skill, 배경 정보는 docs로 분리하기

## 결정
세 번째 안을 택한다.
- CLAUDE.md에는 코드로 알 수 없는 규칙만 둔다. 200줄 미만, 강조 표현 없이 쓴다.
- 반복 절차는 프로젝트 skill로 둔다. 레포에 있어서 계정을 바꿔도 따라온다.
- 대화 모드 같은 개인 선호도 계정 간 이동 때문에 예외적으로 CLAUDE.md에 둔다.
- AGENTS.md로의 전환은 Claude 외 도구를 쓰게 되면 다시 검토한다.

근거: Claude Code 공식 Memory 문서와 Best practices, ETH 실험(arXiv 2602.11988: 불필요한 컨텍스트 파일은 비용을 20% 넘게 늘림), IFScale(arXiv 2507.11538).
