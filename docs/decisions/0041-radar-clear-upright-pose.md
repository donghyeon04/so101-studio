# 0041. `radar_clear`의 기본 자세는 팔을 위로 세운 [0, -90, 85, -90, 0, 3]으로 한다

상태: 확정 · 2026-11-06 (0039의 "기본 후보" 대체, 0039의 조건은 그대로)

## 맥락
결정 0039는 `radar_clear`의 기본 후보를 "손끝을 팔 원점 바로 위 150mm에 두는 접은 자세"로 적었다. 팔 세션이 관절 격자 탐색으로 확인해 보니 이 자세는 기구학상 없다. 링크 점의 작업대 y를 120mm 이하로 두면 손끝 높이가 약 270mm 아래로 내려가지 않는다. 벤치마크는 그동안 기구학을 따지지 않고 이 자세를 흉내 냈다.

## 결정
- `config/robot.yaml`의 `poses.radar_clear` = `[0, -90, 85, -90, 0, 3]`(관절 °). 팔을 위로 세운 자세로, 손끝 작업대 xy (300, 95.8), 높이 약 321mm, 링크 점 y 최대 약 102mm다. 0039의 세 조건(링크 y 120mm 이하, 손끝 150mm 이상, 관절 한계·안전 검사 안)을 모두 만족한다. 시험은 `tests/test_radar_clear.py`(팔 세션, `dev/arm-req-025` a6a164c, 총괄 승인).
- 벤치마크 대기 자세도 이 설정값을 읽는다. demo 씨앗 20개에서 716a144 표 대비 성공률은 같고(낙관 100→100%, 비관 77→78%) 인식 평균은 +1~3초(낙관 86→87초, 비관 86→89초)다. 대기 자세에서 확인 높이 55mm까지 내려오는 이동 때문이다. 100초 기준에는 영향이 없다.
- 이 자세에서 출발하는 `follow_path`는 첫 점까지 `home`·`park`처럼 `plan_goto` 안전 경로로 먼저 간다(지금 IK 실패가 나서 팔 세션이 고치는 중). IK 자체를 고치면 다른 기능에 영향이 있으므로 그때 다시 알린다.
- 1절 공식 숫자는 REQ-025가 합쳐진 뒤 main 값으로 다시 낸다.
