## 결정
1. **그리퍼 두 종 (D3)**: `Gripper` 인터페이스 아래 `SingleJawGripper`(지금 것, 기본)와 `ParallelGripper`(Robonine SO-ARM100/101 Parallel Gripper, 서보 ID 6 그대로)를 둔다.
   - 병렬 그리퍼의 기준점(TCP)은 두 턱 중앙이다. 보정이 필요 없고 기울기는 0, 높이 규칙은 W ≤ G − 4다.
   - 고르기는 `config/arms/<팔>.yaml`의 `gripper: single_jaw | parallel`이고, 세부 값은 `config/grippers/<종류>.yaml`에 둔다. 병렬은 설정으로만 켠다.
   - 접촉 감지와 조임 토크 기준은 그리퍼마다 따로 실측한다. 폭↔서보값 표는 폭 게이지 5점으로 잰다.
   - 병렬 URDF(`assets/so101_parallel.urdf`, 관절 이름 `gripper` 유지)는 결정 4와 같이 만든다.
2. **레이더 서보 (D4)**: MG90S를 OpenRB-150 + XL330-M288-T로 바꾼다.
   - 연결은 A안이다. ESP32와 OpenRB를 UART(3.3V, TX/RX 교차, GND 공통, OpenRB Serial2)로 잇는다. OpenRB는 Dynamixel2Arduino로 XL330을 돌리고 실제 각도를 돌려준다.
   - **XL330 전원은 5V다.** 12V를 OpenRB VIN에 넣지 않는다(XL330 입력은 3.7~6.0V). 0035의 12V→5V 강압 모듈이나 USB 5V를 쓴다. 배선 전에 VIN 전압을 확인한다.
   - 통신은 하위 호환으로 확장한다: `hello.servo = pwm|dxl`, 레이더 샘플에 선택 필드 `ang`. 설정은 `servo.driver`.
   - 교체 이유는 성공률이 아니다(시뮬레이션 차이 ±5%p 안, #144). 0.088° 해상도와 실제 각도 피드백 때문이다. 서보 지연·떨림은 B4 실측으로 확인한다.
   - 구매 목록은 `ultrasonic-spec.md` 3.5에서 갱신한다.
3. **자동 캘리브레이션 전압 (D6)**: 11.0V 기준(0028)을 유지한다.
   - 먼저 전원 경로를 점검한다: 어댑터 정격, DC 잭·보드 단자·케이블에서의 강하, 부하 중 보드 단자 전압. 1번 서보 통신 끊김도 같은 경로로 같이 본다.
   - 그래도 떨어지면 더 센 12V 어댑터를 산다. 측정 전용 기준을 낮추는 안은 마지막이다.
4. **직접 설계 부품의 3D·충돌 (D1)**: 부품마다 STL로 내보낸다. 그리고 "장면 부품 목록"(파일, 붙는 곳 = 작업대 또는 팔 링크, 위치·자세) 설정 하나로 3D와 충돌 검사에 올린다(A).
   - 관절이 있는 병렬 그리퍼만 URDF를 다시 만든다(B).
   - CAD 원본 도구는 아직 모른다. 확인되면 URDF 도구를 고른다(onshape-to-robot / ExportURDF / SW2URDF 등).
5. **다음 기능 순서 (D2)**: 다음 순서로 한다.
   1. 서보 건강 대시보드·경고(8)
   2. 게임패드 조작(3)
   3. 장면 충돌 검사(6, 결정 4와 함께)
   4. 교시·작업 기록을 LeRobot 데이터셋으로(1)
   5. 웨이포인트·블록 프로그래밍(7)
6. **레포 정리 (D5)**:
   - main에 합쳐진 원격 브랜치를 지운다.
   - `dev/gui-handoff-final`을 지운다.
   - 기획 요청함 PR #68을 닫는다.
   - #41(자동 캘리브레이션 반복)은 AC4 실물 합격 뒤 다시 본다.
