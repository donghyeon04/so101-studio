# 0067. 작업대·팔·레이더 자리를 하드웨어 담당 CAD 값으로 정하고, 배출 구역은 판 위 통 하나로 한다

상태: 확정 · 2026-11-18 (사용자 승인: CAD를 기준으로 쓴다, 배출 구역은 오른쪽 귀퉁이 통. 근거 `planning-inbox` `inbox/2026-11-18-h0-cad-values.md`(총괄 H-0). 실물 조립 뒤(H-6) 실측으로 바꾼다)

## 맥락
- 받은 CAD의 판은 600×400이 아니라 425×375(두께 2, 40×80 프로파일 위)이고, 팔 J1과 레이더 축이 판 앞뒤 가운데 근처에 있다. 손목 초음파 브래킷도 바뀌었다(19×52×91.7mm).
- 새 판에서 지금 배출 구역 `right`(480, 150)는 판 밖이다. 판 안에서 집을 수 있고 시연 물체와 떨어진 자리는 팔 옆 앞쪽 귀퉁이뿐이다. 칸 3개를 두면 시연 물체 3개(중심 120mm 간격)의 배치가 크게 준다(무작위 배치 성공 92% → 13~42%, 통 하나면 45~67%, 기획 계산).

## 결정
1. 설정값(작업대 좌표, 결정 0013): `table_mm` {425, 375}, `robot_base_in_table` (215.2, 21.4, yaw 90), `table_z_mm` −2.9, `radar.station_mm` (207.3, 405.5)(서보 축), `radar.height_mm` 23.2, 레이더 축 → 송수신기 앞면 48.7mm.
2. 배출 구역은 오른쪽 귀퉁이의 **통 하나**다(시작값: 가운데 (355, 80), 안쪽 110×110, 벽 높이 25mm). 칸 대신 통 위에서 그리퍼를 열어 떨어뜨린다. 통은 출력물이다.
3. 시연 배치는 반경 120~220mm에 **방위 45~135°**(정면 ±45°)로 줄인다(반경 220의 양 옆이 판 밖이다). 통 둘레(레이더 무시 원)와도 떨어뜨린다. 11/23의 최소 반경 150 검토는 그대로다.
4. 손목 센서 오프셋 `arm_sensor_offset_mm`은 새 브래킷 CAD로 H-2에서 다시 내고, 실물은 A0로 확인한다.
