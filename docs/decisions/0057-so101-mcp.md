# 0057. C11 so101-mcp는 Tibe31/so101-mcp를 영문 경로에 설치하고 프로젝트 범위로만 등록한다

상태: 확정 · 2026-11-13 (사용자 승인, `researching-references`로 후보 10개 비교, 계정 교체 뒤 환경 맞춤. 처음 0054로 썼으나 main의 0054(화면 시험)와 겹쳐 0057로 바꿈)

## 결정
1. Tibe31/so101-mcp(MIT, 88점)를 `C:\tools\so101-mcp`에 설치한다(`uv sync --extra robot`). 한글 사용자 폴더를 피한다.
2. `claude mcp add so101 --scope local`로 이 프로젝트에만 등록한다. `--scope user`는 쓰지 않는다.
3. `config.json`은 예시 그대로다(포트·한계·자세 미설정). 실물 시험 전에 `so101-limits`로 한계를 만들고 사용자가 전원 스위치 옆에 있을 때만 쓴다(`real-arm-runbook.md`).
4. 이 서버는 `ArmService`의 잠금·워치독·기록을 거치지 않고 같은 COM 포트를 쓴다. 우리 `so101.cmd`를 실행하기 전에는 so101 MCP를 끈다.
5. 우리 CLI(`so101.cmd`)가 기본 수단이고 so101-mcp는 초기 탐색용이다.
