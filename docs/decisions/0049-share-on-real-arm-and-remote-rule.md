# 0049. `--share`는 실물에서도 쓴다, 원격은 접속한 쪽 IP로 가린다, `so101.cmd gui --share`는 팔 세션 REQ

상태: 확정 · 2026-11-08 (사용자 승인으로 합침). 0023의 "공유 링크는 시뮬레이션에서만 연다"를 바꾸고, 0047의 원격 판정과 "영향"을 바로잡는다.

## 맥락
결정 0047을 구현하기 전 EGM Stage 9 리뷰(2026-11-08)에서 세 가지가 나왔다.
1. 0023은 "공유 링크는 시뮬레이션에서만"이라 0047의 `--share`와 부딪친다.
2. 0047은 원격을 "루프백이 아닌 것"이라고만 했다. 주소(Host)로 판정하면 같은 PC에서 LAN IP 주소로 연 브라우저가 조작권을 받는다. 그런데 감시 프로세스는 `127.0.0.1`에만 열려 있어 그 브라우저의 heartbeat가 닿지 않고, 1초 뒤 실물 팔이 감시 정지된다.
3. 0047은 "팔 세션 영향 없음"이라 했지만 `so101.cmd gui`의 인자는 팔 세션 영역(`cli/`)이다.

## 결정
1. `--share`는 시뮬레이션과 실물 모두에서 쓸 수 있다. 원격은 보기 전용과 E-STOP뿐이고, 조작권과 감시 heartbeat는 같은 PC(루프백)에만 있기 때문이다. 시연은 실물 팔로 하므로 실물에서 막으면 쓸모가 없다.
2. 원격은 **접속한 쪽 IP가 루프백(`127.0.0.1`, `::1`, `::ffff:127.0.0.1`)이 아닌 브라우저**다. 같은 PC에서 LAN IP 주소로 연 브라우저도 원격이다. 감시 프로세스는 `--share`여도 `127.0.0.1`에만 연다.
3. `so101.cmd gui --share`는 팔 세션이 `cli/`에 인자를 더한다(REQ). 그 전에는 `python -m so101_studio.gui --share`로 쓴다.
4. 구현 세부는 `planning/gui-spec.md` 12.6.

## 영향
- GUI 세션: gui-spec 12.6 전부(원격 판정, 조작권 거부, 웹 포트 버그, IP 표시, 3D 주소, 알림, 운영자 E-STOP 시험 뒤집기).
- 팔 세션: `cli/__init__.py`의 `gui`에 `--share`(store_true)를 더해 넘긴다(REQ, 번호는 총괄이 매김).
