# 0055. GUI 숫자 입력은 값 정보표 하나와 입력 방식 규칙으로 만든다

상태: 확정 · 2026-11-12 (사용자 승인, `researching-references`로 후보 12개 비교, 로컬 총괄). 구현 전에 gui-spec 새 절과 EGM Stage 9(결정 0048).

## 맥락
숫자 칸이 20곳 넘게 흩어져 있고 정상 범위·추천값·기본값이 안 보이며, 모두 숫자 직접 입력이라 사용자가 막막하다(11-12 사용자).

## 결정
1. 값 정보표 하나(`gui/param_meta.py`): 단위, 허용 한계(하드), 추천 범위(소프트), 간격, 설명. 기본값은 `robot.yaml`에서 읽는다(ROS 2 ParameterDescriptor, Blender 소프트·하드 한계). 추천 범위는 실측·설계서·결정에 근거가 있을 때만 적는다.
2. 입력 방식은 규칙으로 고른다(Home Assistant auto, Carbon 지침): 정해진 보기 → 고르는 목록·토글, 의미 있는 범위의 연속값 → 슬라이더 + 숫자 칸(추천 범위 띠), 좌표·정확한 mm·° → 숫자 칸 + 간격 버튼(±1·±5·±10).
3. 칸 아래 "기본 · 추천 · 허용" 한 줄, 추천 밖은 경고색, 허용 밖은 막고 이유, 항목마다 [기본값으로](VS Code), 바꾼 값 강조는 그대로.
4. 공용 부품 하나(`gui/pages/common.py`)로 파라미터 화면부터 좌표·안전·작업대·교시·프로그램·수동 입력 순서로 바꾸고, 0054 화면 시험으로 확인한다.
