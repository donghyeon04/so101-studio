# 0072. 카메라보다 초음파 정확도를 먼저 올린다

상태: 확정 · 2026-11-19 (사용자 판단과 승인. 카메라는 초음파 집어 옮기기가 된 뒤 산다)

## 맥락
- MuJoCo ACT(위·손목 카메라 + 관절, 전문가 시연)는 50번 중 15~17번을 집었다. 파이프라인 검증으로는 됐고, 11-19 밤 학습(`pick2_v2`, 시연 990개)으로 마무리한다.
- 12/4 필수 시연은 초음파 → 집어 옮기기다. 실물 카메라는 아직 없다.
- 병렬 그리퍼는 물체 폭 + 20mm로 벌려 한쪽 여유가 10mm다. M5에서 어긋남 10mm까지는 모두 집혔고 15mm는 일부, 20mm는 실패했다.

## 결정
1. 순서: ① 레이더 조립 뒤 `radar-bringup.md` B1~B4·R1 실측(팔 없이) → ② 실측으로 초음파 센서 모델·필터를 규칙 기반으로 보정하고, 초음파 벤치마크·가상 ESP32의 센서 모델도 실측에 맞춘다 → ③ 모자라면 실물 "스캔 → 물체 위치·크기" 지도학습 추정기를 검토한다(조사 먼저) → ④ 카메라 ACT는 카메라를 산 뒤 실물 시연으로 다시 한다. 강화학습은 그 뒤 필요하면.
2. MuJoCo 초음파(M6)는 2차 그대로다. ACT는 `pick2_v2`로 마무리하고 새 수집은 하지 않는다(L3·L4를 시연에 넣을지는 결정 0071의 11/23 기준).
3. 위치 오차 목표(팔 확인 뒤 위치): 중앙 5mm 이하, 90%가 10mm 안. 방향은 지금 기준(12번 중 10번) 그대로.
4. ③의 추정기는 2차(12/4 뒤)다. 대신 R1·A1·I1 실측 때 스캔 원자료와 정답 자리를 같은 형식으로 남긴다.

## 영향
- `ultrasonic-spec.md` 1절 합격 기준, 8.4 기록, 10절. 초음파 세션: ①② 실측·보정. 총괄: 11/23 범위 점검.
