# 0006. 장치 구성

상태: 확정 · 2026-10-31

## 결정
- 상위 제어기는 Windows PC 1대다 (Python, RTX 5070 Ti, RAM 32GB). 필요하면 학습도 이 PC에서 한다.
- 팔: PC ↔ USB ↔ Seeed 버스 서보 드라이버 보드 ↔ SO-101 팔로워 암. 리더 암은 없다.
- 초음파: PC ↔ USB ↔ ESP32 1개 ↔ HC-SR04 2개. 두 센서는 순차로 측정한다.
- 스캔 서보와 카메라는 아직 없다. 각각 3단계, 4단계에서 레퍼런스를 조사한 뒤 구매한다.
- 학습을 하게 되면 PyTorch는 CUDA 12.8 이상 빌드를 쓰고, `torch.cuda.get_arch_list()`에 `sm_120`이 있는지 확인한다.
