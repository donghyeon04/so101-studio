# 0018. 직접 교시는 레퍼런스의 토크 끈 흐름을 따르고 추종 교시 코드는 제거한다

상태: 확정 · 2026-11-01

## 맥락
결정 0017 이후 레퍼런스 26개를 더 조사했다. 같은 서보(STS3215 팔로워)에서 토크를 켠 채 손으로 밀어 가르친 사례는 없었다. 손으로 가르치는 사례(Poppy, Interbotix, myCobot, Niryo, uArm, Piper, SO-100 Foxglove 튜토리얼)는 모두 토크를 끄고 각도를 일정 주기로 읽어 저장하고 재생할 때만 토크를 켠다. LeRobot 공식 문서는 팔로워를 1/345 기어로, 사람이 움직이는 리더를 기어비가 낮은 서보로 만든다.

## 결정
- 직접 교시는 토크를 끈 `record <이름>` 하나다. 추종 교시, 중력 보정(`gravcal`), 방향 보조, 교시용 P·D·토크 제한 코드는 제거한다.
- 레퍼런스의 공통 절차를 따른다: 토크를 끄기 전에 홈 자세(받침 근처)로 이동, 팔을 잡았다는 확인(Enter), 3초 카운트다운, Enter로 끝. 기록은 20Hz, 한 번에 90초까지.
- 표본마다 실제 시각을 함께 저장해 손으로 움직인 속도가 재생에 그대로 반영된다(시각이 없는 옛 파일은 20Hz 일정으로 본다).
- 리더 팔, PWM 모드, 일부 관절만 풀기는 하지 않는다.
