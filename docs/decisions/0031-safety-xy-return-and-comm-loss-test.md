# 0031. 작업대 XY 검사에 복귀 허용을 넣고, 작업대는 실측으로, 포트 빠짐을 안전 시험에 넣는다

상태: 확정 · 2026-11-04 (0015 보완)

## 맥락
GUI 세션 G10 시험에서 다음 두 가지가 확인됐다. 하나는 0° 자세의 손끝(y 약 402mm)이 작업대 허용 범위(600×400mm, 여유 10mm) 밖이라는 것이다. 다른 하나는, 관절 한계와 바닥 검사에는 "밖에서 출발해 안쪽으로 돌아오는 움직임 허용" 예외가 있는데 작업대 XY 검사에는 없다는 것이다. 그래서 팔이 밖에 있으면 `home`도 `out_of_bounds`로 거부됐다. 사용자는 연결 끊김 경우도 안전 시험에 넣어 달라고 요청했고, 아래 결정안을 승인했다.

## 결정
- XY 검사도 바닥 검사처럼 처리한다. 출발점이 작업대 밖이면, 작업대 밖으로 벗어난 거리가 출발점보다 늘지 않는 점만 허용한다.
- 작업대 허용 범위는 임의로 늘리지 않는다. 실제 책상 크기와 팔 받침 위치를 실측해 `workspace.yaml`에 넣고(T6), 그 전까지 0° 자세 시험은 안전 모드 "자유"로 한다.
- `table_z_mm`와 손끝 위치는 접촉 측정으로 잰다. 조그로 손끝을 1mm씩 내려 종이 한 장이 끼일 때 멈추고, 토크로 자세를 유지한 채 관절값을 FK로 역산한다. 책상 네 곳에서 재서 기울기도 본다. 앞 거리는 책상에 붙인 인쇄 격자의 교차점에 손끝을 대 점 사이 차이로 비교한다.
- 포트 빠짐 시험을 안전 시험에 넣는다. 서보 보드 USB를 홈 정지 중, 편 자세 정지 중(손으로 받칠 준비), 느린 이동 중, 조그 중에 각각 뽑는다. 합격 기준은 다음과 같다.
  - 0.6초 안에 fault가 나고 `ARM-COMM-LOST`와 사고 묶음이 남는다.
  - 팔은 그 자리에서 선다.
  - 다시 꽂아도 사용자가 연결하기 전에는 움직이지 않는다.
  - 다시 연결한 뒤 토크가 켜져 있다.
- 12V 전원을 뽑는 시험은 토크가 꺼져 팔이 떨어지므로 넣지 않고, 물리 비상 정지 스위치를 검토할 때 다룬다.
- 토크 풀림 재현은 눈이 아니라 `status`의 토크 값으로 판단한다. 홈 자세는 받침에 기대 있어 토크가 풀려도 보이지 않는다.
