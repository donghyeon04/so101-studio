# 0066. 학습 플랫폼(다중 시점, 에피소드 수집, ACT, 강화학습 데모)을 12/4 전에 넣는다

상태: 확정 · 2026-11-16 (사용자 승인. 총괄 조사 후보 14개 가운데 상위 셋의 원문을 기획이 확인. 0062의 3번 "M9 강화학습(12/4 뒤)"와 5번 "GUI 잠금은 M8 전까지 유지"를 일부 바꾸고, 0044의 "LeRobot 데이터셋은 뺀다"·"카메라 화면은 숨김"을 바꾼다) · 2026-11-17 사용자 승인: `learning-platform.md` 3a 범위 자르기. 시계 주입(13.10.2)·M6·GUI ② 수집 화면 전체·데이터셋 이어 쓰기·세계 다시 짓기·GUI ③의 [일시 정지]·[다음 배치]·화면 판정·강화학습 데모(L5)를 12/4 뒤 2차로 미룬다(8항의 자르는 순서보다 더 자른다). 11/23 범위 점검은 그대로 한다 · 2026-11-18 ACT 수집 방식과 1차 묶음의 성공 기준은 결정 0068로 바뀜

## 맥락
사용자가 SO-101 Studio를 학습 플랫폼으로 넓히기를 원했다: 한 화면에 여러 시점, 키보드·게임패드 조작 에피소드 수집, ACT·VLA 학습과 실행, 강화학습. "12/4 전에 한 번에, 미루지 않는다"가 조건이다. 실물·초음파 통합(I1)이 시연 필수라는 우선순위는 그대로다. 계획과 원문 확인 결과는 `planning/learning-platform.md`에 있다.

## 결정
1. **단계**: L1 다중 시점(MuJoCo 탑뷰·손목 카메라, 초음파 빔·값) → L2 수집(우리 집기 알고리즘을 스크립트 전문가로 쓴 자동 생성이 1순위, 키보드·게임패드 조작 수집) → L3 ACT 학습(이 PC의 GPU) → L4 정책 실행(`ArmService` 입구로, 안전 검사 그대로) → L5 강화학습 데모. 11/30 기능 동결 안에 넣는다.
2. **수집·실행은 우리 `ArmService` 위에서 한다.** 데이터는 LeRobot 데이터셋 형식(`so101_follower`와 같은 키·단위)이다. so101-nexus의 조작 수집 기능은 쓰지 않는다(리더 팔 전제, `lerobot<0.6` 요구).
3. **강화학습(0062-3 변경)**: so101-nexus 환경에서의 짧은 학습 데모(L5)는 12/4 전에 한다. 우리 앱과 별개 환경임을 화면과 문서에 적는다. 우리 장면·`ArmService` 위의 강화학습(시험장 실행기 B)과 실물 이어 배우기는 그대로 12/4 뒤다.
4. **실물에서 학습한 정책 실행은 12/4 전 범위에 넣지 않는다.** 시뮬레이션까지다. 실물 카메라가 ESP32-CAM(Wi-Fi) 한 대이고 학습 데이터에 맞지 않기 때문이다(결정 0058-6).
5. **VLA는 12/4 전 범위에서 뺀다.** 나중에 같은 데이터로 학습할 수 있게 에피소드마다 과제 문장을 함께 적는다.
6. **설치**: 앱 환경 `so101`에는 `lerobot[dataset]`만 더한다(numpy 2.2.6 conda 설치본이 바뀌지 않는 것이 조건, 바뀌면 `--no-deps`로 빠진 것만). CUDA torch(RTX 5070 Ti용), 학습용 lerobot, `so101-nexus-mujoco`(버전 고정, `teleop` extra 없이)는 **새 conda 환경 `so101-train`**에 넣는다. 앱은 지금의 CPU torch로 정책을 실행하고, 모자라면 그때 다시 승인받는다. 버전은 `environment.yml`과 새 `environment-train.yml`에 `==`로 고정한다.
7. **GUI 잠금(0062-5 변경)**: 수집 화면과 정책 실행 화면에 한해 "다음 배치로 세계를 다시 짓기"를 허용한다. 그 밖의 화면의 시나리오 거부·물체 편집 거부는 M8까지 그대로다.
8. **밀릴 때 자르는 순서**: L5 → 게임패드 수집 → 키보드 수집. L1, 스크립트 전문가 수집, ACT(시뮬레이션)는 남긴다. 못 들어온 단계는 "된 데까지"로 시연한다.
9. aviadarn/so101-lerobot은 LICENSE가 없어 코드를 가져오지 않고, 공개된 수치(300개 시연·4만 스텝 42~50%, 600개 88~90%)와 배운 점(손목 카메라 고정, 체크포인트는 실행 성공률로 고름)만 기준으로 쓴다.
