# 0074. 12/4 전 비교 실험은 시뮬레이션 둘(초음파 인식, 집기 방식)로 하고 카메라는 뺀다

상태: 확정 · 2026-11-20 (사용자 결정, 총괄이 전달. 결정 0058의 카메라 비교를 12/4 뒤로 미루고, `comparison-experiment.md`의 "성적표 숫자는 실물만"을 바꾼다)

## 맥락
- 비교 실험 주는 11/23~29다. 처음 계획은 실물에서 초음파와 카메라(결정 0058)를 같은 배치로 비교하는 것이었다.
- 카메라가 없고, 레이더 조립과 실물 팔 연결 날짜도 아직 모른다. 실물만 기다리면 비교 실험 주에 낼 숫자가 없다.
- 시뮬레이션 도구는 이미 있다: 초음파 벤치마크(결정 0037, 실제 `radar.py`·`check.py`를 그대로 돌림)와 MuJoCo 시험장의 ACT 평가(결정 0062·0071).

## 결정
1. **(가) 초음파 인식**: 가상 ESP32 벤치마크의 고정 시나리오 `demo`·`demo80`·`single`·`spread120`을 씨앗 200개씩 돌려 성공률, 인식 시간, 위치 오차, 방향 정답률을 낸다. 작업 실행을 끝까지 돌린 시간을 manual(정답 좌표)과 비교한다. 초음파 세션이 잰다.
2. **(나) 집기 방식**: MuJoCo `collect_pick2` 씨앗 30000~30199에서 규칙 기반(스크립트 전문가)과 ACT v2 100k를 비교한다. 성공률, 실패 유형, 시간, 씨앗별 짝 표(둘 다 성공 / 한쪽만 / 둘 다 실패)를 낸다. MuJoCo 세션이 잰다.
3. **카메라 인식은 12/4 전 비교에서 뺀다.** 결정 0058의 기종과 방식은 카메라를 사면 그대로 쓴다.
4. **실물이 오면 같은 표에 실물 열을 더한다**: 레이더 R1·I1(정답 쌍, `ultrasonic-spec.md` 8.4·8.6), 실물 팔 집기. 시뮬레이션 숫자는 "시뮬레이션" 열로 따로 적고 실물 숫자와 섞지 않는다.
5. 숫자의 출처는 결정 0037대로 도구, 커밋, 시나리오, 씨앗 범위를 함께 적는다.
