# 0005. 개발 순서: 팔 먼저

상태: 확정 · 2026-10-31

## 맥락
팔이 아직 움직여 본 적이 없다. 팀은 팔의 떨림, 작동 이상, 실제 도달 범위를 확인하기 전에 센서, GUI, 추가 출력물을 정하는 것은 의미가 적다고 판단했다.

## 결정
아래 순서로 진행한다. 0~2단계는 센서 없이 할 수 있다.

| 단계 | 내용 |
|---|---|
| 0. 구동 점검 | 캘리브레이션, 관절별 가동 범위, 떨림, 반복 정밀도, 온도·전류 |
| 1. 팔 동작 라이브러리 | 대기 자세, MoveJ, MoveL, `pick(x, y, 각도, 폭)`, 배출. 좌표는 손으로 입력 |
| 2. 작업 공간 확정 | 실측 도달 범위로 작업대, 집는 구역, 배출 구역, 센서 스테이션 위치를 정함 |
| 3. 초음파 인식 모듈 | 스캔 서보 구매, 스테이션 설계, 0004 인터페이스로 출력 |
| 4. 카메라 인식 모듈 | 카메라 구매, 같은 인터페이스로 출력 |
| 5. 비교 실험과 GUI | 같은 물체와 배치로 두 인식 방식 비교, GUI 설계 |

- 작업 공간은 "긴 직사각형 작업대, 팔은 뒤쪽 변 가운데" 배치를 가설로 두고 2단계에서 확정한다.
- URDF 계산 기준 참고값: 수직 하강 집기 반경 약 12~28cm, 어깨 회전 ±110°.
