# 0034. 초음파 인식은 작업대 레이더로 후보를 찾고 팔 손목 센서로 확인하는 2단계로 한다

상태: 확정 · 2026-11-05 (두 모드는 0038로 대체, 0006 보완, `system-architecture.md` 4~6절과 `features.md` C2~C4의 두 스테이션 방식 대체)

## 맥락
원래 계획은 작업대 가장자리의 두 스테이션이 HC-SR04를 서보로 돌려 위치와 방향을 구하는 것이었다. 기획 세션이 가상 센서로 다섯 가지 배치를 비교했다(조사 기록은 커밋하지 않음, 팀 공유 페이지 2판). 센서가 옆을 보는 방식(두 스테이션, 레이더 하나, 레일형 XY)은 성공률이 11~28%였다. 매끈한 면이 비스듬하면 반사가 돌아오지 않고, 앞 물체가 뒤 물체를 가리고, 빔이 멀수록 퍼진다(30cm에서 지름 8~16cm). 위에서 내려다보는 손목 센서는 88~98%였다. 사용자와 팀은 레이더로 찾고 팔로 확인하는 혼합안을 골랐고, 시간을 줄이는 방법을 모두 넣으라고 했다.

## 결정
- 작업대 앞 변 가운데에 HC-SR04 1개를 스캔 서보에 단 "레이더"를 둔다. 레이더는 물체 후보의 대략 위치만 구한다.
- 팔 손목에 HC-SR04 1개를 아래로 향하게 단다. 팔이 후보 위를 십자 → 원형 → 십자로 지나가며 중심과 긴 축(방향)을 구하고, 그 결과로 집는다.
- 작업 순서에 확인 단계(`CHECK`)를 `DECIDE`와 `PICK` 사이에 넣는다. 결과는 기존 `ScanResult`·`DetectedObject` 형식이라 집기·GUI·비교 실험은 바뀌지 않는다.
- 시간을 줄이는 방법을 모두 넣고 설정으로 켜고 끈다. 레이더 연속 왕복, 각도 간격 4°, 먼저 보이면 바로 출발, 다음 찾기를 놓는 동안 미리 하기, 여러 바퀴 합치기, 접근 경로를 첫 확인선으로 쓰기, 물체를 지나면 확인선 멈추기다. 정확 모드(가상 센서 78~93%, 3개 인식 약 26초)와 빠른 모드(77~88%, 약 17초)를 둔다.
- 서보 기종, 치수, 통신 규약, 작업 순서는 `docs/planning/ultrasonic-spec.md`에 둔다. 서보 기종은 사용자 승인 뒤 확정한다.
- 숫자는 가상 센서 값이다. 빔 반경과 면 각도 한계를 실측한 뒤 다시 계산한다.
