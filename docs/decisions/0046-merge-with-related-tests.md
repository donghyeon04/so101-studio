# 0046. PR은 관련 테스트로 합치고 전체 테스트는 하루 한 번

상태: 대체됨(→ 0064) · 2026-11-07 (사용자가 로컬 총괄과 정함). 0045의 1번 중 "합치기 전에는 전체를 돌린다"를 바꾼다.

## 맥락
전체 pytest가 약 45분이고 GUI 고정 포트 때문에 한 번에 하나만 돌릴 수 있어, PR마다 전체를 돌리면 합치기가 밀린다.

## 결정
1. PR을 합치기 전에는 main과 합친 뒤 관련 테스트만 돌린다: 바뀐 파일의 테스트와 그 기능을 쓰는 GUI 테스트, `-m "not slow"`. 작성 세션은 PR 본문에 돌린 명령과 결과를 적는다.
2. 전체 테스트는 하루 작업을 마칠 때와 실물 시험 전에 총괄이 한 번 돌린다. 실패하면 그날 합친 PR에서 원인을 찾는다.
3. 총괄의 `code-review`(medium 이상)는 PR마다 그대로 한다 (0045-3).
