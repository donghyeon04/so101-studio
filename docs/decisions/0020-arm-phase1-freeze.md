# 0020. 팔 1차 완료 기준은 API 동결이고, 하드웨어 실측은 병행한다

상태: 확정 · 2026-11-02

## 맥락
팔 작업(T0~T11, C1, S1~S3)은 구현됐지만 실측(`table_z_mm`, T6 줄자, T7 실물 집기), 전원 점검, 그리퍼 재설계가 남았다. 이것들이 끝날 때까지 기다리면 시뮬레이션·GUI 시작이 늦어진다. 초음파 센서도 팀 일정상 시간이 걸린다.

## 결정
- 팔 1차 완료 = `ArmService`와 `Studio`의 함수 이름과 입출력을 고정(API 동결)한 시점으로 본다. 이 시점에 2차 단계(시뮬레이션·GUI)를 시작한다.
- 동결 시점에 빠진 API 3개(인식 방식 선택·스캔, 단계 진행 `step()`, 실행 중 물체 추가)는 GUI 단계의 첫 작업으로 추가한다.
- 하드웨어 실측(자로 재기), 전원 계통 점검, 그리퍼 재설계 뒤 T7은 시뮬레이션·GUI 개발과 병행한다. 이 작업들은 API를 바꾸지 않는다.
