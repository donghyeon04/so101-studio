# 작업대(판) 하드웨어 설계 요구사항

상태: 초안 · 2026-11-07 (로컬 총괄 작성, 2026-11-13 기획이 4절 손목 브래킷·4.1 카메라 거치대 세부 요구사항 보완, 설계 담당 하드웨어 담당에게 전달용. 수치는 지금 소프트웨어 설정·설계서에서 가져왔다. 판 크기·거리·배출 구역은 기획 세션 검토와 사용자 결정으로 확정)


> **2026-11-18 결정 0067로 바뀐 값**: 하드웨어 담당 CAD가 기준이다. 판 425×375(두께 2, 40×80 프로파일 위), 팔 원점 (215.2, 21.4), 레이더 축 (207.3, 405.5)·센서 높이 23.2mm, 배출 구역은 오른쪽 귀퉁이 통 하나(가운데 (355, 80), 안쪽 110×110, 벽 25mm). 아래 표의 600×400·(300, 61)·(300, 400)·배출 구역 표시는 처음 요구값으로 남긴다.
## 한 장 요약
- 판 위 **작업 면 600 × 400mm**(좌우 × 앞뒤). 팔은 앞 변 가운데에 받침 뒤 끝을 가장자리에 붙여 클램프로 고정, 초음파 레이더는 맞은편(뒤) 변 가운데, 둘 사이 약 339mm.
- **좌표 원점 = 작업 면 왼쪽 앞 모서리(0, 0)**, x는 오른쪽(긴 변), y는 레이더 쪽, 높이는 작업 면 위 mm. 그리드는 이 원점에서 mm 단위로 적는다.
- **레이더 센서 중심은 작업 면 위 20mm**, 수평으로 팔 쪽을 본다. 서보 몸체는 작업 면 아래에 두어 혼이 면 높이에 오게 한다.
- **테두리는 없거나 3mm 이하로 낮게**(예시 이미지처럼 열린 판). 레이더 시야(160° 부채꼴) 안에 세워진 것을 두지 않는다.
- 판은 **평평하고 단단하게**(휨 1mm 이하), 팔은 **다시 붙여도 같은 자리**(±1mm)에 오게 위치 고정 핀이나 턱을 둔다.

|---|---|---|

| 좌표 원점 | 작업 면 왼쪽 앞 모서리 | 팔에서 레이더 쪽을 보고 왼쪽 |

| 레이더 회전축 | (300, 400), 정면이 −y(팔 쪽) | 뒤 변 가운데. 회전축 위치 오차 ±2mm 안 |
| 배출 구역(놓는 곳) | 중심 (500, 150), 80×80mm | **판 안의 낮은 평면 표시로 확정**(판 밖 상자는 집기 범위 밖). 표시 외에 벽·상자를 세우지 않는다 |

| 시연 물체 자리 | 팔 원점에서 120~220mm, 물체 중심 사이 120mm 이상 | 인식 성공률이 가장 좋은 띠 |

**600×400과 팔·레이더 거리 약 339mm는 적절하다(기획 검토, 2026-11-07).** 크기를 바꾸고 싶으면 가능하다(소프트웨어는 설정 파일 숫자만 바꾸면 된다). 다만 앞뒤(팔↔레이더 거리)를 늘리면 레이더 측정 거리가 늘어 정확도가 떨어지고(최대 600mm 설정), 줄이면 레이더와 팔이 너무 가까워진다. **330~360mm를 권장**한다(앞뒤 400mm 판이면 약 339mm).

## 2. 팔 고정
- 팔 무게 767g(실측), 팔을 뻗을 때 받침에 걸리는 비틀림 약 1N·m. 클램프나 볼트가 이 힘에 들리거나 돌지 않아야 한다.
- **다시 붙여도 같은 자리**: 위치 고정 핀 2개, 또는 받침 판이 닿는 턱(ㄱ자 모서리)으로 ±1mm 안. 위치가 바뀌면 소프트웨어 좌표를 매번 다시 재야 한다.
- **받침 뒤 끝을 판 앞 가장자리에 딱 붙이고 그 끝을 클램프로 고정**한다(사용자 결정 2026-11-07). 받침은 판 위에 바로 놓아 받침 바닥면과 작업 면을 같은 높이로. 지금 소프트웨어의 작업 면 높이(−35mm)는 캘리브레이션 오차까지 섞인 보정값이라 조립 뒤 다시 잰다(URDF상 받침 바닥은 모델 원점 2.4mm 아래).
- 팔 받침(y 0~87)과 팔 원점 둘레 반경 90mm 안은 물체를 두지 않는 곳이라 판 위에 무엇이 있어도 된다(케이블 등).

## 4. 손목 초음파 브래킷 (H4, 2026-11-13 세부 요구사항)
**하는 일**: 작업 실행의 `CHECK`에서 팔이 레이더 후보 위를 지나가고, 손목 센서가 바로 아래(작업 면이나 물체 윗면)까지 거리를 잰다(`ultrasonic-spec.md` 3.3·6절). 센서는 그리퍼를 보는 것이 아니라 **그리퍼 옆에서 바닥을 본다**. 턱은 빔 밖에 있어야 한다.

> 2026-11-14: 실제 브래킷은 팀 CAD "Gripper(브라켓 짧은 버전)"로 정했다(결정 0063). 센서 면은 손끝에서 99.5mm 위, 옆 66.5mm이고 빔 안 간섭이 없다(M7a #335). 아래 표의 높이(50~60mm)·옆 거리(30mm 이상)는 2026-11-13 요구값으로 남긴 기록이고, 지금 소프트웨어 값은 `config/ultrasonic.yaml`의 {0.6, 66.5, 99.5}다.

좌표는 손끝 기준 도구 축이다: x = 턱이 벌어지는 축, y = x에 수직인 옆, z = 손끝에서 손목 쪽(위). 손끝은 단동식이면 고정 턱 끝, 병렬이면 두 턱 가운데다.

| 항목 | 요구 | 이유 |
|---|---|---|
| 방향 | 센서 면이 그리퍼 축과 **평행하게 아래**(손끝이 수직 아래면 센서도 수직 아래). 기울기 0°, 허용 ±5°(작을수록 좋다) | 물체 높이 = 센서 높이 − 거리로 계산한다. 5° 기울면 센서 높이 110mm에서 재는 점이 약 10mm 옆으로 밀린다. A0 보정은 한 높이에서만 맞춘다 |
| 높이 | 센서 면(원통 앞면)이 턱 끝보다 **50~60mm 위**(지금 소프트웨어 값 55mm) | 확인할 때 손끝을 작업 면 위 55mm에 두므로 센서는 약 110mm. 물체(최대 40mm) 윗면까지 70mm로, HC-SR04 최소 거리(약 20~30mm)보다 충분히 멀다 |
| 옆 거리 | 두 원통의 가운데가 **턱에서 30mm 이상** 떨어지게, 턱이 벌어지는 축(x)이 아니라 **옆(y)으로** 둔다(지금 값 x 0, y 30) | 빔 반각 최악 15°면 55mm 아래에서 빔 반경이 약 15mm, 원통 반경 8mm를 더해 약 23mm. 가동 턱은 x축으로 최대 약 90mm까지 벌어지므로 x쪽에 두면 열린 턱이 빔에 들어온다 |
| 보드 방향 | 두 원통이 놓인 긴 변(보드 약 45×20mm)을 x축과 나란히 | 두 원통이 턱에서 같은 거리가 된다. 소프트웨어는 센서를 두 원통 가운데 한 점으로 본다 |
| 빔 앞 | 원통 앞 ±15° 원뿔 안에 브래킷·나사·케이블·턱이 없다 | 가까운 것의 메아리를 물체로 읽는다 |
| 아래쪽 한계 | 브래킷의 어느 부분도 센서 면보다 아래로 나오지 않는다(그래서 턱 끝보다 50mm 이상 위) | 바닥 안전 검사는 턱 끝만 본다 |
| 간섭 | 손목 굽힘 ±103.6°, 손목 회전 ±168.8°, 그리퍼 0~100(최대 벌림 약 90mm) 전체에서 아래팔·손목 서보·턱에 닿지 않는다. CAD에서 끝 자세로 확인한다 | 집기에서 손목을 최대 35° 기울이고 손목을 돌린다 |
| 강성·재현성 | 흔들리지 않게. 떼었다 붙여도 ±1mm 같은 자리(육각 너트 홈이나 맞춤 턱) | 팔 확인 목표가 위치 오차 중앙값 5mm다. 자리가 바뀌면 A0 보정을 다시 한다 |
| 케이블 | 4선(VCC·TRIG·ECHO·GND) 약 1.5m. 브래킷에 케이블 타이 자리를 두고, 원통 앞을 지나지 않게 하며, 손목 회전 범위만큼 여유 | `ultrasonic-spec.md` 3.3 |
| 출발점 | TheRobotStudio `SO101_Wrist_Cam_Hex-Nut_Mount_32x32_UVC_Module`(STEP, Apache-2.0)의 붙는 부분을 그대로 쓰고 카메라 칸을 HC-SR04 칸으로 바꾼다. 출력은 채움 40%, 트리 서포트 | `ultrasonic-spec.md` 3.6 |

- **카메라 마운트 각도를 쓰지 않는다**: 손목 카메라 마운트는 카메라가 턱 끝을 보도록 기울어 있다(공식 마운트도 그렇다). 초음파는 기울이지 않는다(0°). 그래서 카메라 마운트를 고쳐 쓸 때 붙는 부분만 쓰고 센서 칸은 그리퍼 축과 평행하게 다시 세운다.
- **그리퍼 두 종(단동식·Robonine 병렬)**:
  - 같은 브래킷을 쓸 수 있는 것은 브래킷이 붙는 부품이 두 그리퍼에서 같을 때뿐이다. Robonine 그리퍼가 육각 너트 홈이 있는 그리퍼 고정 몸체를 바꾸면 그대로는 맞지 않는다. Robonine STL에서 붙는 면이 같은지 먼저 확인한다.
  - 권장 구조는 두 조각이다. **붙는 부분**(그리퍼마다)과 **센서 홀더**(공통)를 나사로 잇는다.
  - 붙는 부분이 같아도 턱 모양이 달라 높이 50~60mm·옆 30mm 조건을 병렬 그리퍼로도 따로 확인한다. 병렬은 두 턱이 x축 양쪽으로 벌어지므로 y쪽에 두는 규칙은 같다.
  - 오프셋은 그리퍼마다 따로 재고, 그리퍼를 바꾸면 A0를 다시 한다.
- **돌려줄 것**: 그리퍼마다 손끝 기준 두 원통 가운데의 x·y·z(mm), 센서 면 기울기, 브래킷 STEP(또는 STL). 오프셋은 `config/ultrasonic.yaml`의 `arm_sensor_offset_mm` 설계값이 되고, STL은 장면 부품으로 3D와 충돌 검사에 올린다(결정 0043-4).

## 4.1 위 카메라 거치대 (H8, 2026-11-13 세부 요구사항)
비교 실험 카메라(AI-Thinker ESP32-CAM, 결정 0058)는 **손목이 아니라 작업대 위에 고정**한다. 작업 면 네 모서리 ArUco 마커로 픽셀을 작업대 mm로 바꾸므로 카메라가 움직이면 안 되고, Wi-Fi라 프레임 지연이 고르지 않아 움직이는 손목에는 맞지 않는다. 손목 카메라는 VLA 단계에서 USB 카메라로 따로 더한다(그때는 턱 끝을 보게 기울인다).

| 항목 | 요구 | 이유 |
|---|---|---|
| 높이 | 렌즈가 작업 면 위 **500~700mm**에서 조절되게(시작 550mm) | 작업 면 600×400mm와 네 모서리 마커가 화면에 모두 들어와야 한다. 기본 렌즈 화각(약 66°)의 기준(대각·가로)을 실물로 확인하기 전이라 높이를 바꿀 수 있게 한다 |
| 방향 | 렌즈가 **수직 아래**, 작업 면 가운데를 본다. 기울기 ±5° | 호모그래피가 기울기를 보정하지만 화면 안 해상도를 고르게 하려고 |
| 기둥 자리 | 작업 면 바깥(판 모서리나 뒤쪽 변 바깥)에 세운다. 팔이 움직이는 공간과 레이더 시야(작업 면 위 20mm, 160° 부채꼴)에 들어오지 않게 | 팔과 부딪히지 않고 레이더가 기둥을 물체로 읽지 않게 |
| 강성 | 팔이 움직이거나 책상이 흔들려도 화면이 떨리지 않게 판에 볼트로 고정 | 흔들리면 물체 위치가 튄다 |
| 기판 고정 | ESP32-CAM 기판(약 27×40mm)은 고정 구멍이 없어 끼우는 홈이나 케이스로 잡는다. 렌즈 앞은 열어 초점을 돌릴 수 있게 한다(첫날 550mm에 맞춤). 받침 보드(ESP32-CAM-MB)를 붙인 채 쓰면 그 크기와 USB 케이블 자리를 둔다 | 결정 0058 |
| 안테나 | 기판의 PCB 안테나 쪽을 금속으로 덮지 않는다 | Wi-Fi 끊김 |
| 전원·열 | 5V를 넉넉히(2A급 USB), 케이블은 기둥을 따라. 케이스에 바람구멍 | 전압이 떨어지면 리셋되는 보고가 많다. 동작 중 뜨거워진다 |

## 5. 테두리
- **권장: 테두리 없음(열린 판) 또는 높이 3mm 이하의 얇은 테.** 레이더 센서가 면 위 20mm에 있어, 그보다 높은 테두리는 빔에 걸려 큰 반사를 만든다. 빈 판에서 미리 재 둔 기준값으로 지우긴 하지만, 테두리 가까이(30mm 안) 놓인 물체는 놓치기 쉽다.
- 물체가 떨어지는 것이 걱정되면 테두리를 **작업 면보다 낮게**(판 옆면만) 하거나, 레이더 부채꼴 밖(팔 쪽 앞 변)에만 둔다.
- 배출 구역은 판 안 낮은 평면 표시다(확정). 상자를 두지 않는다. 놓인 물체는 소프트웨어가 레이더 후보에서 뺀다(REQ-045).

## 6. 바닥 면과 그리드(정확도 판정용)
- **원점과 단위**: 작업 면 왼쪽 앞 모서리를 (0, 0)으로, x(오른쪽)·y(레이더 쪽) 모두 mm.
- **선**: 10mm 가는 선, 50mm 중간 선, 100mm 굵은 선. 100mm마다 숫자(0, 100, 200 … 600 / 0 … 400). 예시 이미지처럼 0~10 칸 번호가 아니라 **mm 숫자**로 적어야 소프트웨어 좌표와 바로 맞는다.
- **표시할 점**: 팔 원점 (300, 61) 십자(받침이 덮으면 받침 윤곽선으로 대신), 레이더 축 (300, 400) 십자, 팔 원점 중심 원 반경 90·120·220·250mm(집기 범위와 시연 띠), 배출 구역 80×80mm 사각.
- **인쇄 정확도**: 선 위치 오차 ±0.5mm 안, 전체 600mm에서 늘어남 1mm 이하(인쇄 배율 확인용으로 100mm 자 표시를 넣으면 좋다).
- **재질**: 평평하고 단단하며 무광. 손목 센서가 위에서 내려다보므로 소리를 흡수하는 천·스펀지·두꺼운 고무 매트는 피한다. 무광 인쇄 + 얇은 코팅 또는 판에 직접 인쇄. 나중에 카메라를 달 수 있어 반사(광택)를 줄인다.
- **평탄도**: 전체에서 휨 1mm 이하. 팔이 집을 때 턱 끝이 면 위 5mm까지 내려가므로 휘면 부딪히거나 못 집는다.

## 7. 그 밖에
- **판 재질·두께**: 팔 클램프를 견디는 단단한 판(예: 12mm 이상 MDF·합판, 또는 알루미늄 프레임 위 판). 바닥에 미끄럼 방지 발.
- **배선**: 12V 어댑터, 팔 서보 보드, ESP32, OpenRB, 5V 강압 모듈을 판 아래나 뒤쪽에 고정하고 케이블이 작업 면을 가로지르지 않게. **전원 스위치는 손이 바로 닿는 곳**(실물 시험 때 사람이 옆에서 대기한다).
- **카메라 자리**: 4.1. 판 모서리나 뒤쪽 변에 기둥을 세울 볼트 구멍을 둔다.
- **시험 물체**: 50×50×40mm, 40×80×40mm, 30×100×40mm(가로×세로×높이), 단단하고 면이 평평한 것. 실물 시험 때는 58×58×39mm를 썼다.

## 8. 설계가 끝나면 돌려받을 것
1. 판·작업 면 크기, 그리드 원점 위치.
2. 팔 원점(어깨 회전축) 좌표와 받침 높이(작업 면 기준).
3. 레이더 회전축 좌표, 센서 중심 높이, 대기 방향.
4. 손목 센서 오프셋(그리퍼마다, 손끝 기준 x·y·z, 4절)과 위 카메라 렌즈 위치·높이(4.1).
5. 배출 구역 위치와 형태.
6. 부품 STEP 파일(레이더 스테이션, 손목 브래킷, 카메라 거치대, 그리퍼 개조, 판). 받으면 3D 화면과 충돌 검사에 넣는다(결정 0044).

## 9. 조립 뒤 소프트웨어 쪽에서 할 일
- `config/workspace.yaml`의 팔 원점 y를 실측값(약 61mm)으로 고친다(지금 50).
- 작업 면 높이(`table_z_mm`)를 다시 잰다(runbook 실물 시험 순서 4번).
- 레이더 기준값(빈 작업대 3바퀴, `config/ultrasonic_baseline.json`)을 다시 잰다.
- 손목 센서 오프셋, 레이더 축 위치·높이를 돌려받은 값으로 `config/ultrasonic.yaml`에 넣는다.
