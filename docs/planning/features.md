# 기능명세서·메뉴트리

상태: 초안 · 갱신 2026-11-01

범위 층은 `overview.md`를 따른다. **필수**는 12/4 시연에 반드시 있어야 하고, **목표**는 카메라 비교용, **선택**은 여유가 있을 때 한다.

## 시연 시나리오 (기능 도출의 기준)
1. 빈 작업대를 스캔해 기준값을 저장한다.
2. 상자·막대형 물체 2~3개를 임의의 각도로 놓는다.
3. 스캔을 시작하면 GUI 평면도에 물체의 위치와 방향이 표시된다.
4. 팔이 가까운 물체부터 그리퍼를 물체 방향에 맞춰 회전한 뒤 집어 배출 구역에 놓는다. 남은 물체가 없으면 멈춘다.
5. 추정값과 실제값을 비교한 결과표를 보여준다.
6. (목표) 같은 배치를 카메라 모드로 실행하고, 조명을 끈 상태로 다시 실행해 두 방식을 비교한다.

## 메뉴트리
GUI 메뉴와 페이지는 `gui-spec.md` 3절이 기준이다(5개 그룹 13개 페이지, `decisions/0023`). 이 문서의 옛 메뉴트리는 대체됐다. 실험 기능(F3, F4)은 팀 검토에 따라 나중에 붙인다.

## 미정 사항
- 팔 소프트웨어 구조와 구현 순서는 `arm-software-spec.md`에 있다.
- 집기 실패 판정 방법 (D4)
- 스캔 서보는 MG90S(결정 0035), 스캔 간격은 4°(`ultrasonic-spec.md` 4절)
