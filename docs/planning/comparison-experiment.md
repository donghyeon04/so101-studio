# 초음파·카메라 인식 비교 실험 계획

상태: 초안 · 갱신 2026-10-31

## 목적
같은 픽 앤 플레이스 작업에서 초음파 인식과 카메라 인식 중 어느 쪽이 더 나은지, 그리고 각 센서가 유리한 환경이 어디인지 확인한다.

## 통제 변인
- 바뀌는 것은 인식 모듈뿐이다. 두 인식 모듈은 같은 출력 `[{x, y, 각도, 폭, 길이, 신뢰도}]`를 낸다 (`decisions/0004`).
- 판단(우선순위, 명령 생성)과 제어(pick, place)는 같은 코드를 쓴다.
- 같은 물체, 같은 배치, 같은 작업대 좌표계에서 측정한다.
- 크기·방향 추정은 센서마다 계산법이 다르므로 인식 모듈에 속한다.

## 평가 기준
| 기준 | 측정 방법 |
|---|---|
| 위치 정확도 | 실제 위치와 추정 위치의 오차(mm) |
| 방향 정확도 | 0/45/90/135° 분류 정답률 |
| 인식 속도 | 스캔 1회에 걸리는 시간(초) |
| 집기 성공률 | 인식부터 놓기까지 끝까지 성공한 비율 |
| 비용 | 초기 비용은 BOM으로 계산. 유지보수 비용과 교체 주기는 문헌 값 인용 |
| 환경 강인성 | 아래 조건별로 정확도가 얼마나 떨어지는지 |

## 환경 조건 가설 (테스트로 확인 필요)
센서 원리에서 추린 후보다. 카메라는 빛의 반사를, 초음파는 소리의 반사를 쓴다.

### 카메라만 흔들릴 것으로 보는 조건
| 조건 | 예상 영향 |
|---|---|
| 어둡거나, 조명이 깜빡이거나, 밝기가 바뀜 | 노출 변화로 윤곽이 흐려짐 |
| 그림자, 역광, 광택면 반사 | 그림자를 물체로 오인하거나 경계를 놓침 |
| 물체 색이 배경과 같음 | 색으로 구분 불가 |
| 투명 물체 (페트병, 유리) | 거의 보이지 않음. 초음파는 감지 가능 |

### 초음파만 흔들릴 것으로 보는 조건
| 조건 | 예상 영향 |
|---|---|
| 온도 변화 | 음속이 1°C에 약 0.18% 변해 거리 오차 (20°C 차이면 약 3.5%) |
| 초음파 대역 소음 (압축공기 누설, 다른 초음파 센서) | 가짜 반향 |
| 바람, 기류 | 측정값 흔들림 |
| 흡음 재질 (스펀지, 천) | 반향이 약해 놓침 |
| 매끈한 면이 비스듬히 놓임 | 정반사로 반향이 돌아오지 않음 |
| 작거나 얇은 물체, 서로 붙은 물체 | 빔 폭(약 15°) 때문에 구분 불가 |

## 예상 시나리오
- 초음파가 유리할 장면: 어두운 곳, 조명 변화, 투명하거나 배경과 같은 색인 물체.
- 카메라가 유리할 장면: 작은 물체, 촘촘한 배치, 정밀한 각도.

## 미정 사항
- 시험 물체 목록과 개수, 배치별 반복 횟수
- 정답 위치·각도를 재는 방법 (작업대 눈금, 지그 등)
- 카메라 인식 방식 (OpenCV 규칙 기반 또는 YOLO-OBB)과 카메라 기종
- ACT 같은 end-to-end 정책을 세 번째 참가자로 넣을지 여부
