## 사용자 의견 (기획 세션 전달용, 결과 리포트에 붙일 것)
2026-11-01, 사용자 의견. 기획 세션에서 다룰 내용이며 이 세션에서 구현하지 않는다.

- URDF와 FK가 있으니, 팔의 자세와 움직임을 시뮬레이션 화면에서도 똑같이 보여 줄 수 있으면 좋겠다.
- 시뮬레이션에서 구현한 이 화면(자세, 관절 상태 등)을 나중에 GUI에도 붙이고 싶다.
- 나중에 결과 리포트를 쓸 때 이 의견을 근거로 붙인다.

개발 세션 메모 (기술적 가능성, 미검증): 필요한 재료는 이미 있다. `assets/so101_new_calib.urdf`(+메쉬), `Kinematics.fk`, `SimDriver`(관절값을 그대로 돌려줌). 실제 팔과 같은 `JointState`를 모델에 넣으면 같은 자세를 화면에 그릴 수 있다. 렌더링 방법은 후보일 뿐이며(placo/meshcat 뷰어, 웹 GUI의 three.js URDF 로더, MuJoCo 등) 기능명세서의 GUI 기술 결정 때 조사해 고른다.
