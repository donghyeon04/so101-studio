# 프로젝트 기획서

상태: 초안 · 갱신 2026-10-31

## 한 줄 정의
카메라 없이 저가 초음파 센서 2개로 물체의 위치·크기·방향을 인식해 SO-101 로봇팔이 집어 옮긴다. 같은 작업을 카메라 방식과 비교해 각 센서가 유리한 환경을 밝히고, 전체를 GUI로 제어·모니터링한다.

## 배경
- 과목: 자동차센서공학. 기획 발표 2026-09-11 완료.
- 팀원 모두 "초음파 센서로 픽 앤 플레이스"라는 대전제에 동의했다.
- 차별점: 기존 초음파 프로젝트는 위치만 판단한다. 이 프로젝트는 같은 스캔 데이터로 크기와 놓인 방향까지 판단하고, 그리퍼를 그 방향에 맞춰 회전한다.

## 일정과 평가
| 항목 | 내용 |
|---|---|
| 최종 마감 | 2026-12-04 |
| 평가 방식 | 교수 앞 시연 + PPT 발표. 보고서 제출 가능성 있음 |

## 최종 산출물
1. 실제로 동작하는 시연 세트 (작업대, 센서 스테이션, 팔)
2. 제어·상태 확인용 GUI
3. 비교 실험 결과 (`comparison-experiment.md`)
4. 공개 배포: GitHub 저장소로 공개해 다른 사람이 설치·재현하고 레퍼런스로 쓸 수 있게 한다. 실행 파일(.exe)은 필수가 아니다.

## 범위
| 층 | 내용 | 12/4에 없으면 |
|---|---|---|
| 필수 | 초음파 인식(위치, 방향) → 팔 픽앤플레이스 시연. 기본 GUI(스캔 시작, 인식 결과 표시, 팔 상태). GitHub 공개(README, 설치 방법) | 프로젝트 실패 |
| 목표 | 카메라 인식 모듈(OpenCV 규칙 기반) + 비교 실험(정확도, 속도, 조명 조건 1~2개) | 발표 이야기가 약해짐 |
| 선택 | YOLO-OBB, ACT 세 번째 참가자, 환경 조건 전부, 설치 스크립트, GUI 고도화 | 아쉬움 정도 |

기능별 층 구분은 `features.md`에 있다.

## 주간 일정 (초안)
| 주 | 기획 (원격 세션) | 소프트웨어 | 하드웨어 | 지원 |
|---|---|---|---|---|
| 1주 (11/2~8) | 범위, 기능명세서, 메뉴트리 | 팔 구동 점검, 동작 라이브러리 | 스캔 서보 조사·주문 | 카메라 조사·주문, 실험 물체 준비 |
| 2주 (11/9~15) | 와이어프레임, 디자인 | `pick(x, y, 각도)` 완성, ESP32 스캔 펌웨어 | 작업대, 센서 거치대 설계·출력 | 실험 기록 양식 |
| 3주 (11/16~22) | 개발 지원 | 초음파 인식 모듈, 1차 통합, 기본 GUI | 스테이션 설치, 배선 | 중간 시연 영상 |
| 4주 (11/23~29) | 비교 실험 설계 확정 | 카메라 모듈, GUI 완성 | 카메라 거치 | 비교 실험 측정 |
| 5주 (11/30~12/4) | 보고서·발표 구성 | 버그 수정, 레포 정리 | 시연 세트 점검 | PPT, 보고서, 리허설 |

스캔 서보와 카메라는 배송 기간(국내 2~3일, 해외 1~2주) 때문에 1주차에 주문한다.
