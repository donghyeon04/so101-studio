# 프로젝트 기획서

상태: 초안 · 갱신 2026-10-31

## 한 줄 정의
카메라 없이 저가 초음파 센서 2개로 물체의 위치·크기·방향을 인식해 SO-101 로봇팔이 집어 옮긴다. 같은 작업을 카메라 방식과 비교해 각 센서가 유리한 환경을 밝히고, 전체를 GUI로 제어·모니터링한다.

## 배경
- 과목: 자동차센서공학. 기획 발표 2026-09-11 완료.
- 팀원 모두 "초음파 센서로 픽 앤 플레이스"라는 대전제에 동의했다.
- 차별점: 기존 초음파 프로젝트는 위치만 판단한다. 이 프로젝트는 같은 스캔 데이터로 크기와 놓인 방향까지 판단하고, 그리퍼를 그 방향에 맞춰 회전한다.

## 일정과 평가
| 항목 | 내용 |

## 최종 산출물
1. 실제로 동작하는 시연 세트 (작업대, 센서 스테이션, 팔)
2. 제어·상태 확인용 GUI
3. 비교 실험 결과 (`comparison-experiment.md`)
4. 공개 배포: GitHub 저장소로 공개해 다른 사람이 설치·재현하고 레퍼런스로 쓸 수 있게 한다. 실행 파일(.exe)은 필수가 아니다.
