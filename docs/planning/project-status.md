## 실제 팔에서 확인한 것 (2026-11-07, `measurements.md`)
- 점검: `doctor` 정상(서보 6/6, 12.1~12.3V), `linkwatch` 125초 끊김 0번, `radar_clear` 자세 케이블 문제 없음.
- 높이: `table_z_mm` −35는 11-06 해석 오류였다(그날 명령의 40은 모델 z). −15로 고친 뒤 40mm 명령에 37/40/40mm.
- 집기·놓기 4/4(쥔 부하 23~30%, 턱이 책상에 닿지 않음). 놓을 때 고정 턱이 제자리로 보임(경로는 실행됨, 손 이동 18.8mm가 눈에 안 띔) → 기획 세션에서 재설계.
- 손끝 방향 8점: 손끝 높이가 명령 ±9mm, 가장 멀리 뻗은 점만 −11mm(처짐).
- 사고: 그리퍼 첫 열기에서 서보 6개 동시 응답 없음, powertest 뒤 편 자세에 남아 토크 꺼짐·팔 떨어짐(REQ-047로 고침). 사용자 관찰은 "편 자세에 닿자마자 6개가 한꺼번에 풀림", 어댑터 12V 5A. 서보 보호 설정에는 전압 항목이 없어 순간 전원 처짐에 의한 리셋으로 본다. 동작을 순하게 하는 안(REQ-048 D1~D4)은 사용자가 원인 기록(D6)만 승인했다.
- 교시 재생 변환본: 11-06 기록이 지금 작업대 범위 밖이라 57/453점에서 잘림. 작업대 조립 뒤 새로 기록해 다시 본다.
