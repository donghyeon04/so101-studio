## 성능 (가상 값, 시연 배치 `demo`, 씨앗 60)
| 항목 | 가상 값 | 기준 |
|---|---|---|
| 물체 3개 성공 | 낙관 약 97%, 비관 약 84% (pwm 서보) | 10회 평균 2개 이상 |
| 인식 시간 | 평균 약 85초 | 평균 100초 이하(임시) |

- 접근 호버 도달 띠는 지금 유지(결정 0042, 손실 2~4%p, A1 때 다시 본다).
- XL330(dxl)로 바꿔도 성공률 차이는 ±5%p 안이다(#144). 숫자는 센서 실측(B1·B2) 뒤 다시 낸다(결정 0037).

## 실제 팔에서 확인한 것 (2026-11-06, `measurements.md`)
- 0° 자세 수평 도달 353mm, 집기·놓기 재시험 5/5, 교시 재생은 0.5배속 통과(0.75배속은 `step`으로 멈춤 → #135 루프 따라잡기 줄임).
- 문제: 1번 서보 쪽 통신 끊김이 다시 생김(하드웨어, runbook "문제가 나면"), AC4는 끝까지 밀 때 전압 10.4~10.7V로 11.0V 기준에서 멈춤.
